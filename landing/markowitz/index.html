Mean-Variance Optimization

Harry Markowitz, 1952. The problem: given n assets with expected returns μ and covariance matrix Σ, find the portfolio weights w that minimize risk for a given target return.

minimizew   wTΣw  —  portfolio variance
subject to   wTμ = rtarget  —  target return
              Σwi = 1  —  fully invested
              wi ≥ 0  —  no short selling

The efficient frontier is the set of all portfolios that maximize return for a given risk. No portfolio below the frontier is optimal — you can get more return for the same risk. The tangency portfolio (maximum Sharpe ratio) is the point where the capital market line touches the frontier.

This is a threshold problem: as target return increases, the optimal portfolio crosses thresholds where new assets enter the allocation. The same mathematics as Erdős–Rényi phase transitions — edges (assets) enter the portfolio at critical values of the Lagrange multiplier.
