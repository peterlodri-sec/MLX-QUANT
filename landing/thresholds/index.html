Unifying principle

All threshold phenomena share the same structure:
  
  Below critical value: disordered / fragmented / real
  At critical value:     sharp transition / phase change
  Above critical value:  ordered / connected / complex

The critical value is always a function of the system parameters:
  Graph:      p_c = 1/n
  Ternary:    scale = mean(|w|)  →  round(w/scale) flips at 0.5
  Portfolio:  λ such that w_i(λ) crosses from 0 to positive
  Options:    σ such that P(ITM) > 0.5
