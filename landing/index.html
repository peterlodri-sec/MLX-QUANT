The Backyard Ultra of Autonomous Intelligence: Loop Engineering, MCPs & Agentic Endurance

N. Flyxion & P. Lodri • Axiom Quant Research Monograph

In a Backyard Ultra (pioneered by Lazarus Lake at Big's Backyard Ultra), runners must complete a 4.167-mile loop every hour, on the hour, indefinitely until only one runner remains. There is no fixed distance, no finish line — only the continuous loop of execution. 

Hour 01 ───► Lap 1 (4.167 mi) ───► Reset / Recover ───► Hour 02 ───► Lap 2 (4.167 mi) ...
Turn 01 ───► Prompt / Tool   ───► Observation     ───► Turn 02 ───► Reflect / Act ...

In autonomous AI systems, Loop Engineering is the discipline of structuring long-horizon reasoning into clean, deterministic, self-correcting laps.

2. The 6 Pillars of Loop Engineering

  1. LLMs as Base Reasoning Engines: The LLM is the stride engine of the loop. Each turn ingests previous observations, evaluates progress against the invariant goal, and determines the next atomic action.
  2. Agents as Goal-Oriented Runners: An Agent is an LLM bound to a specific persona, toolset, and objective function. An agent does not stop until empirical runtime verification proves success.
  3. Coding Agents & Self-Correcting TDD Laps: Coding agents run iterative refinement loops: 
    RED (Write Test) ───► GREEN (Minimal Fix) ───► REFACTOR (Clean Code)
  4. Skills as Equipping Modules: Skills are composable, file-backed instruction packages (SKILL.md). Just as a runner selects hydration vests or trail shoes for specific weather, an agent equips specialized skills (/canvas-design, codebase-memory-mcp, n8n-validation) based on loop demands.
  5. MCP (Model Context Protocol) Support Crew: MCP servers act as persistent support crews:
    • codebase-memory-mcp: High-level graph search (search_graph, trace_path).
    • chrome-devtools-mcp: Live DOM inspection & Web performance profiling.
    • cloudrun: Serverless GCP deployment and compute orchestration.
  6. Loop Engineering & State Control: Deterministic state persistence across loops (working_memory.md, scratchpads, git commits) outlives context truncation.

The Ultramarathon: Deep Mathematics of Thresholds

N. Flyxion & P. Lodri • Axiom Quant Research Monograph

1. Zeta Zeros ≡ Random Matrix Eigenvalues

Montgomery (1973), over tea with Dyson at Princeton, discovered that the pair correlation of Riemann zeta zeros matches the GUE (Gaussian Unitary Ensemble) random matrix eigenvalue spacing: 

ρ(u) = 1 - (sin(πu) / πu)²

Threshold connection: The zeta zeros form a point process on the critical line $\text{Re}(s) = 1/2$. Their spacing statistics encode a "spectral rigidity" — zeros repel each other (level repulsion), just like eigenvalues of random matrices. This repulsion is a threshold phenomenon: zeros cannot get too close. The minimal spacing is governed by the same kernel that appears in the transfer operator's correlation decay.

2. Wigner Semicircle ≡ Free Central Limit Theorem

Wigner (1955): the eigenvalue density of an $N \times N$ random symmetric matrix with i.i.d. entries converges, as $N \to \infty$, to the semicircle: 

ρ(x) = (2 / πR²) √(R² - x²),   |x| ≤ R

The moments are Catalan numbers: $m_{2k} = C_k \cdot (R/2)^{2k}$, where $C_k = \frac{1}{k+1}\binom{2k}{k}$. Catalan numbers count non-crossing partitions, Dyck paths, binary trees, and polygon triangulations.

3. Ising Model ≡ Max-Cut ≡ NP-Hard Optimization

The Ising Hamiltonian $H(\sigma) = -J \sum_{\langle ij \rangle} \sigma_i \sigma_j$ on a graph $G = (V,E)$ is mathematically equivalent to Max-Cut. At the critical temperature $T_c$, the spin system undergoes a phase transition from paramagnetic (disordered) to ferromagnetic (ordered). This $T_c$ is the physical manifestation of the graph's cycle rank $\beta_1$.

Dyadic Transformation & Context Realizability

N. Flyxion & P. Lodri • Axiom Quant Research Monograph

The dyadic transformation $T(x) = 2x \pmod 1$ maps the unit interval to itself, generating the canonical Bernoulli shift. When extended to context transition graphs, the cycle rank $\beta_1$ determines the exact field extension required to close holonomy.

1. Spanning Trees & Cycle Rank

For any context graph $G = (V, E)$, the cycle rank is given by $\beta_1(G) = |E| - |V| + k$, where $k$ is the number of connected components.

  • If $\beta_1 = 0$, $G$ is a forest, and all admissible transition assignments are $\mathbb{R}$-realizable.
  • If $\beta_1 = 1$, the minimal witness $K_3$ (triangle) forces a complex amplitude field $\mathbb{C}$.
  • If $\beta_1 \ge 2$, dense cycle overlaps force quaternionic $\mathbb{H}$ or octonionic $\mathbb{O}$ structures.

1. VPIN Information Leakage

VPIN measures order flow toxicity by sampling volume buckets $V$: 

VPIN = (Σ |V_b - V_s|) / (N * V)

The Transfer Operator & the Devil's Staircase

N. Flyxion & P. Lodri • Axiom Quant Research Monograph

1. Frobenius-Perron-Ruelle Operator

For a map $f: X \to X$, the transfer operator $\mathcal{L}$ acts on density functions $\rho$ as: 

(L ρ)(x) = ½ ρ(x/2) + ½ ρ((x+1)/2)

The discrete spectrum consists of eigenvalues $\lambda_k = 2^{-k}$ with Bernoulli polynomials $B_k(x)$ as eigenfunctions. The spectral gap $1 - \lambda_1 = 1/2$ governs the rate of correlation decay in chaotic dynamics.
